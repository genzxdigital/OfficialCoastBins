## Publish on GitHub Pages
1. Replace the existing files in the `CoastBins` repository with these files.
2. Commit the changes to the branch your GitHub Pages site uses (usually `main`).
3. In GitHub, open **Settings → Pages** and confirm the site is deploying from the correct branch.
4. In **Settings → Pages → Custom domain**, enter `coastbins.com`.
5. Keep the `CNAME` file in the repository root.

## IONOS domain
After GitHub Pages is configured for the custom domain, update the DNS records for CoastBins.com in IONOS using the current values GitHub provides for custom domains. Do not delete email-related MX records if your business email depends on IONOS mail.

## Quote form
The form is intentionally serverless. It opens the visitor's email app with a pre-filled request addressed to `info@coastbins.com`.


## Direct email quote delivery

The quote form is configured with FormSubmit so submissions are sent directly to:

**info@coastbins.com**

Important: the first time the form is submitted after publishing, FormSubmit may send a one-time activation email to `info@coastbins.com`. Open that email and confirm the form. After activation, future website submissions are delivered to the business inbox automatically.
